## 🔬 核心科学发现概览 (Graphical Abstract)

![图解摘要 Graphical Abstract](figures/graphical_abstract.png)

1. **确立 SCN CCK 神经元的夜间钙活动峰值**：SCN 腹外侧区域的 CCK 神经元游离钙活动峰严格锁定在主观夜间早期（ZT14-ZT18），与白天放电活跃的 VIP 神经元呈现完美的昼夜反相。
2. **夜间制动抵消光致相位延迟的分子刹车**：在主观夜间（CT14）施加光脉冲通常诱发大幅度相位延迟；而同步激活 CCK 神经元释放 CCK-8S，通过突触后 CCK-B 受体抑制放电，特异性抵消光致延迟，充当保护稳健性的分子刹车。
3. **维系单细胞网络相干同相振荡**：遗传消融 CCK 神经元后，单细胞生物钟虽能振荡但发生严重离散去同步化（Kuramoto 序参量腰斩）；外源补充 CCK-8S 可完全挽救网络同步化。
4. **稳健性与可塑性的“双刃剑”演化权衡**：特异性损毁 CCK 神经元虽然削弱了日常抗杂散光干扰的鲁棒性，却使小鼠在 8 小时极端时差（Jet lag）重夹带中的适应速度提速超过 50%（从 8.5 天缩短至 4.2 天）。
